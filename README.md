# マンガ制作スタジオ

受注から納品までを1画面で進めるマンガ制作の管理ツール。

## 使い方

`index.html` をブラウザで開くだけです。インストールは不要で、入力内容はブラウザの中に自動保存されます。

## 制作の流れ

1. 活用ツール・案件設定
2. ヒアリング（90分・オンライン）
3. 構成・作風を選ぶ
4. 全編シナリオ　★文字の段階で一度止める
5. 校正
6. コマ割り　★ここでも直せる
7. 作画
8. 納品

## 主な機能

- HPのURLを読み込んでヒアリング項目と案件情報を自動で埋める
- 構成案とシナリオの下書きを作る
- 写真からキャラクターの作風見本を作る
- 絵を見ながらセリフを直し、コマ単位で修正依頼を残す
- 1ページだけの作り直し指示を出す
- キャラはJPG/PNG、シナリオはWord、マンガはPDF/JPG/PNGで書き出す

## AIキーについて

URLの読み込み・シナリオの下書き・キャラ見本の生成には、[OpenRouter](https://openrouter.ai/) のAPIキーが必要です。
キーは画面から入力します。**入力したキーはお使いのブラウザの中だけに保存され、このリポジトリには含まれません。**

キーなしでも、入力・編集・書き出しの機能はすべて使えます。
